# Goal loop

## Sub-features

Empty goal list, loading, populated goal, zero mature denominator, waiting, unreviewed answers, contract gap, draft PR, paused/revoked permission and invalid dates.

## How to get to it (user POV)

Select the project and open Goal loop. The empty page explains the first committed goal. A synced goal shows separate tracking, PR, merge, release, signal and outcome evidence.

## Driving it with the browser

Capture the empty page before sync. Run the local helper, then refresh and verify the displayed mature/qualified/waiting counts match its literal report. No complete rate is shown for zero mature workspaces. Missing external events show unknown coverage, not zero users. Compare the before/after receipts and confirm missing release proof prevents a release-win claim. Pause an active owner policy and confirm its durable revision changed. Revoke it and confirm only a new explicit draft grant is offered. Enter reversed cohort dates and confirm a plain error. Check a narrow viewport for readable controls and no horizontal page overflow. Failure is a count mismatch, a later stage inferred from PR state, a blocked control shown as successful, an uncaught error or clipped content.

## Gotchas

The live main branch was unprotected during this unit. The actual pilot stays draft; a protected fake upstream exercises the permitted merge/release path. A provider deployment receipt is not business-state proof. Release tags in events remain producer claims until matched to provider evidence. A retry must not restart the first-entry clock, including across release labels.
