# Afterspan build state

The requested outcome-platform release covers generic outcomes and evaluations, tracing SDKs and interoperability, failure-to-experiment-to-release workflows, and operational proof. The authoritative acceptance matrix is [Outcome platform release](docs/outcome-platform-release.md).

## Production baseline

Primary Traces, nested timings and missing-evidence handling are deployed. Tracker's catalog, parameter and environment-comparison answers have pre-send source checks. Request environment and tool read scopes remain distinct. These checks are producer-side observations, not independent Afterspan source verification or full task usefulness.

The existing product loop supports bounded goals, tracking repair and release evidence under explicit policies. It is not yet a general evaluator and experiment platform. Historical attestations and prior release evidence retain their original scope.

## In progress

Generic workflow checks are being added on the outcome-platform branch. They are not deployed. The acceptance matrix lists implementation, test, operating and release work still required across all four areas.

## Other product work

Replay, surveys and optional hosted billing remain separate from this release. Existing documented billing verification limits still apply. No infrastructure scale, enterprise readiness or outcome improvement is claimed without its own measurements.
