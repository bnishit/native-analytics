Self-hosted analytics. One owner credential; separate write-only keys for each project.

OpenAPI contract · Complete agent operating guide · Dashboard · Source, SDKs and setup

Agents should read the contract, use the JSON CLI, send a stable event ID, and verify the stored receipt. Never put credentials in a browser bundle or URL.

Producer API

Bearer project write key. No dashboard reads.

POST /v1/events    {"events":[{"id":"stable-id","name":"save.completed","distinct_id":"opaque-user","properties":{"kind":"article"}}]}
POST /v1/identify  {"distinct_id":"opaque-user","attributes":{"plan":"starter","tags":["new"]}}
POST /v1/erase     {"distinct_id":"opaque-user"}

Erasure deletes that project's identity and events, and blocks queued events from recreating it. Use a new generation-scoped opaque identity for later legitimate activity.

Owner API

Bearer admin key or owner session. Cookie writes require the CSRF header and same origin.

GET/POST /api/projects
POST     /api/projects/{id}/rotate-key
GET      /api/overview?project=my-app
GET      /api/events?project=my-app
GET      /api/people?project=my-app
PATCH    /api/people?project=my-app
POST     /api/query?project=my-app
GET/POST /api/charts?project=my-app
DELETE   /api/charts/{id}?project=my-app
POST     /api/maintenance

Query metrics: count, users, sum, average, p95. Property equality filters and hourly/daily buckets. Read the OpenAPI contract for types and bounds.
