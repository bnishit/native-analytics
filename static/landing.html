A FEW GOOD QUESTIONS

Less mystery.
By design.

Is the full suite available today?+

Not yet. This build includes analytics, linked journeys, retries, fixed evidence queries, collector verification, read access controls and a local MCP bridge. Email accounts, customer workspaces, invites and member roles now work in the local build. Hosted email delivery still needs configuration and live verification. Funnels, entry breakdowns, saved behavior/trait segments, calendar retention, a data dictionary and scoped request audits are included. The default self-hosted edition has no paid plans or commercial quotas. Replay, surveys and richer tracing remain planned.

Does Afterspan need my users' private content?+

Many useful metrics need only events and numeric fields. The planned recording and AI-content features will need explicit collection boundaries, masking, separate access and retention. They are not enabled by this page.

Can my coding agent change the product?+

The analytics connection reads aggregates and chart definitions in one project. A separate workspace management connection can invite teammates and change roles within an explicitly delegated workspace role. Account signup, workspace-key issuance and invite acceptance stay with the person. The workspace bridge can save, update, delete and analyze funnels, segments and retention. A third, audit-only connection discovers approved meanings and follows request evidence without exposing raw records. No billing account is required. Neither bridge deploys code or publishes surveys.

What about bots, desktop tools and CLIs?+

The existing server collectors and constrained app relay support event measurement beyond the browser. Visual replay is a separate web capability; a CLI or bot will need its own event and agent timeline.
